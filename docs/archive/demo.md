# 발표·시연 체크리스트 (8주차, 발표 15분 + 질의 5분)

발표는 **발표 슬라이드 `/deck/index.html`**(13장) + 시연은 실제 서비스. 팀 페이지(`#/team`)는 평가 항목별 상세 근거(질의응답·채점용).
- 슬라이드: F 전체화면, **P 발표자 화면**(대본·다음 장·15분 타이머), → 단계 진행, 1~9 장 이동
- 5장(시연): 휴대폰 틀 안이 진짜 앱이라 그대로 눌러서 시연 가능(앱 안에서도 ←/→ 는 슬라이드가 받음)
- 13장: 오늘의 챌린지 순위가 4초마다 갱신 — 1장 QR 로 청중을 참여시키고 마지막에 공개

## 발표 전날
- [ ] 배포 주소 3개를 `apps/web/src/lib/team.ts` 의 `links` 와 `apps/web/public/deck/deck.js` 의 `CONFIG` 에: 서비스(Vercel) · GitHub · Swagger(Render `/docs`)
- [ ] 팀원·역할을 `TEAM.members` 에
- [ ] 다른 PC·휴대폰에서 세 주소가 열리는지
- [ ] `scripts/ai_eval.py` 결과(docs/ai-eval.md)가 최신인지
- [ ] 테스트 `cd api && ../.venv/bin/python -m pytest -q`

## 발표 10분 전
- [ ] Render 서버 깨우기(서비스 주소 한 번 열기 — 무료 서버는 15분 쉬면 잠듦)
- [ ] 랭킹 페이지(`#/live`)를 다른 탭에 열고 '⛶ 크게'
- [ ] 효과음은 끈 상태로(🔈)

## 15분 순서(팀 페이지 칸 순서와 같음)
| 분 | 칸 | 시연 |
|---|---|---|
| 0~1 | 한눈에 | QR 로 청중 참여 시작(랭킹 탭) |
| 1~3 | 문제·Needs, 시장 | 근거 숫자(유튜버 ‘오른다’ 평균, 자극어), 설문 |
| 3~6 | 시스템·AI | 실제 게임 1라운드: 유튜버 카드(과거 적중·🔥) → AI 질문 → 근거 칩·✓검증 → 공매도 → 속보 → 정답 |
| 6~9 | AI 검증 | 짓궂은 질문 라이브: "회사 이름이 뭐야?" "20일 뒤 얼마?" → 거절·근거 없음, 검증 표시 펼치기 |
| 9~11 | UI/UX | 휴대폰 화면, 상태 처리, 개선 사례 |
| 11~13 | 데이터·성능 | 데이터 페이지 품질 점검 0건·텍스트 분석, 응답 속도, 보안 |
| 13~15 | 실패와 개선, 랭킹 | 청중 랭킹 공개 🥇 |

## 시연 중 문제가 생기면
- 서버가 안 깨면: 로컬(`npm run dev:lan` + uvicorn)로 전환
- AI 가 한도에 걸리면: 화면의 '⏳ n초 뒤 다시 묻기'가 바로 오류 대응 시연이 된다
