# UI/UX 고도화 계획 (2026-11-14)

평가 기준(금융빅데이터분석실습 10주차 안내)에서 화면과 직접 닿는 항목:

| 항목 | 배점 | 이 단계에서 보여줄 것 |
|---|---|---|
| UI/UX·사용성 | 20% | 이용 흐름, 쉬운 설계, **로딩·오류·빈 결과 처리**, **사용성 개선 사례** |
| 데이터·API 활용 | 10% | **데이터 출처 명시와 분석 페이지**(필수) |
| 시스템 설계·구현 | 30% | 화면 ↔ 데이터 계층 분리(서버 붙일 자리), 오류 대응 |
| 발표·시연 | 10% | 프로젝터에서도 읽히는 화면, 시연이 끊기지 않는 흐름 |

LLM 기능(AI 애널리스트·해설)은 이번 단계에서 빼고, 자리만 남긴다.

## 원칙

1. **한 화면에 한 가지 결정.** 카드 고르기 → 비중 정하기 → (사건) → 결과. 결정 버튼은 엄지 닿는 아래쪽에 고정.
2. **긴장감은 결과 공개에.** 이름 가리기·미래 차트 그리기·숫자 올라가기 애니메이션은 정답 공개 때 몰아 쓴다. 판단하는 화면은 차분하게.
3. **색만으로 말하지 않는다.** 상승 빨강·하락 파랑에 ▲▼ 기호를 같이 쓴다. `prefers-reduced-motion` 이면 움직임을 줄인다.
4. **숫자는 DB 값만.** 해설 문장은 규칙으로 만든다(사건 효과, 고점·저점, 유튜버 맞음/틀림). LLM 이 붙어도 숫자는 여기서 온다.
5. **끊기지 않는 시연.** 새로고침해도 진행 중인 게임이 이어지고, 데이터를 못 불러오면 다시 시도 버튼이 나온다.

## 화면

| 경로 | 화면 | 핵심 |
|---|---|---|
| `#/` | 홈 | 한 문장 소개, 움직이는 미니 차트, 데이터 규모, 시작/이어하기, 3단계 방법 |
| `#/play` | 라운드 | 진행 막대(10칸, 결과 색), 자금 카운트업, 상황 카드, 카드 뒤집기, 비중 선택(금액 미리보기) |
| (play 안) | 중간 사건 | '속보' 인터스티셜, 산 날→사건일 차트가 그려지며 등장 |
| (play 안) | 정답 공개 | 20거래일 카운트다운 → 미래 구간 차트 그리기 → 이름 공개 → 비교 막대 → 규칙 해설 |
| `#/report` | 리포트 | 성향 카드(이미지 저장), 자금 곡선(나·유튜버·코스피), 정보 습관, 카드별 적중률, 라운드 다시 보기 |
| `#/data` | 데이터·분석 | 출처 3곳, 수집 규모, 문제 은행 구성, 유튜버 적중률 분석, 미래 정보 차단·마스킹 방법 |
| 기타 | 404·오류 | 빈 화면 없이 홈으로 |

## 상태 처리

- 로딩: 스켈레톤(홈 숫자, 라운드 카드 자리). 3초 넘으면 "서버가 깨어나는 중" 문구(Render 무료 플랜 대비).
- 오류: 원인 한 줄 + 다시 시도. 화면 렌더 오류는 ErrorBoundary 가 잡아 홈으로.
- 빈 결과: 공시 0건, 유튜버 영상 1개 등 카드마다 빈 상태 문구.
- 진행 저장: localStorage(실패해도 게임은 동작).

## 사용성 개선 기록

바꾼 이유와 전후를 `docs/ux-log.md` 에 남긴다(발표 '사용성 개선 사례' 재료).

## 구현 순서

1. 구조: 라우터·스토어·데이터 계층(api.ts)·디자인 토큰, Motion 도입
2. 라운드 화면 재작성(카드 뒤집기, 비중 선택, 하단 고정 바, 첫 판 코치마크)
3. 중간 사건·정답 공개 연출, 규칙 해설
4. 리포트(자금 곡선, 성향 카드 이미지 저장)
5. 홈·데이터 페이지
6. 상태 처리·접근성·반응형(데스크톱 2단) 점검, 브라우저 검증

## 3차(11-14): 게임처럼 — 마스코트·성장·효과음

사용자 요청: "귀여운 캐릭터·이모지, 실제 주식 게임·다른 레퍼런스 참고해서 제대로". 참고한 것과 가져온 원리:

| 레퍼런스 | 가져온 원리 | Foresight 에서 |
|---|---|---|
| 듀오링고 | 마스코트가 상황마다 반응, 연속 기록, XP·레벨, 배지 | 부엉이 **새벽이**(8가지 표정), 🔥 n연속, XP·9단계 레벨, 배지 18개(숨은 배지 2개) |
| 토스증권 | 큰 숫자 하나, 색으로 방향, 짧은 문장 | 결과 큰 수익률, 빨강▲/파랑▼, 대사 한 줄 |
| 로빈후드 | 성공 순간의 축하(색종이) | 적중·S/A 등급 색종이, 큰 손실엔 파란 비 |
| 카훗 | 결과를 순서대로 공개하는 긴장감, 순위 | 20일이 그려진 뒤 도장, 누가 더 잘했나 👑 |
| 모의투자 게임(가상 자금) | 잃어도 괜찮은 연습장 | 1,000만 원 가상 자금, "진짜 돈이 아니잖아요 🫂" |

원칙
- 캐릭터·그림은 직접 그린 SVG(외부 캐릭터·이미지 없음). 새벽 = 앞을 내다보는 시간 → 부엉이.
- 새벽이는 **정보를 주지 않는다**(정답 힌트 없음). 규칙 설명·감정 반응·데이터 사실(hindsight 통계)만 말한다.
- 효과음은 기본 꺼짐(강의실), 🔈 버튼으로 켬. 파일 없이 Web Audio 로 합성. 휴대폰은 진동.
- '움직임 줄이기' 설정이면 움직임을 끈다.
- 경험치·배지는 이 기기(localStorage)에만. 같은 라운드는 두 번 보상하지 않는다.
