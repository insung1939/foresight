# 타임슬립 개미 — 2차 설계 (2026-11-21)

1차(26주 시뮬레이션)를 직접 끝까지 플레이해 보고 게임 디자이너 관점에서 냉정하게 다시 봤다. 원칙은 하나다. **누구나 30초 안에 첫 재미를 느끼고, 한 판 끝나면 "한 판만 더"가 나와야 한다.**

## 1. 자체 피드백 — 1차의 부족한 점

| # | 문제 | 왜 문제인가 | 2차에서 |
|---|---|---|---|
| F1 | 첫 화면부터 종목 20개, 숫자, 탭 4개 | 처음 온 사람은 무엇을 해야 할지 모른다(인지 부하) | **연습 시즌 8주 · 6종목**으로 시작한다. 성공 경험을 3분 안에 준다 |
| F2 | 매주 결과 창을 닫아야 넘어간다 | 26번 반복하면 지루하다. 킥루의 재미는 빠른 템포다 | 평범한 주는 **3초 리캡 카드**만 띄운다(자동으로 사라짐). 큰 주(±5%, 1등 탈환, 패닉, 사건)만 큰 창. **▶▶ 4주 그대로** 빨리 감기 |
| F3 | 캐릭터와 감정이 없다 | 숫자만 오가는 게임은 정이 안 간다 | **캐릭터 캐스트**: 내 개미(6종 중 선택, 저마다 특성), 유튜버 라이벌은 동물 유튜버로 매주 한마디, 사건 NPC, 코치 부엉이 |
| F4 | 한 판 끝나면 남는 게 칭호 하나 | 수집하고 꾸미는 이유가 약하다 | **시즌 미션 3개 → 별 ★ → 3D 내 방 가구·개미 옷 해금**. 플레이 → 별 → 방 꾸미기 → 다시 플레이 |
| F5 | 화제성은 🔥 개수뿐 | 전염병 주식회사의 "퍼지는 게 눈에 보이는" 재미가 없다 | **3D 화제 광장**: 종목 가판대마다 개미 군중이 몰린다(군중 = 실제 언급 수). FOMO가 눈에 보인다 |
| F6 | AI는 결산 코치뿐 | 플레이 중에 AI와 상호작용할 일이 없다. 평가 기준의 LLM·RAG 활용이 약하다 | **개미 비서(RAG)**: 종목 시트에서 "이 종목 왜 화제야?"라고 묻는다. 그 시점까지의 영상 제목·공시만 pgvector로 찾아 Gemini가 출처와 함께 답한다. 시즌당 3번 |
| F7 | UI/UX 용어집이 문서에만 있다 | 평가자가 화면에서 바로 확인할 수 없다 | **UX 렌즈**: 켜면 화면 위에 실제 적용된 용어집 용어 배지가 뜬다(바텀시트, 코치마크…). 발표 시연용 |
| F8 | 데이터(Supabase)는 저장만 한다 | "데이터를 활용"하지 않는다 | Supabase(PostgreSQL)에 판·주간 기록·질문을 쌓고, 데이터 페이지에서 **플레이어 vs 유튜버** 분석을 보여준다. pgvector로 RAG |

## 2. 핵심 루프

```
[내 개미 고르기] → 시즌(연습 8주 / 정규 26주 / 오늘의 시드 26주)
   매주: 피드(화제 광장 3D·영상·공시) → (사건) → 사고팔기(바텀시트, 개미 비서에게 묻기) → [다음 주 ▶] 또는 [▶▶ 4주]
   → 3초 리캡(라이벌 한마디) / 큰 주는 큰 창
결산: 등급·칭호·미션 ★ → 정체 공개 → 코치 → 공유
메타: ★로 3D 내 방 꾸미기 · 개미 옷 · 칭호 도감 · 시장 해금 · 오늘의 시드 랭킹·연속 참여
```

## 3. 캐릭터

| 캐릭터 | 역할 | 특성(전략을 바꿈) |
|---|---|---|
| 직장인 개미 🐜💼 | 기본 | 4주마다 월급 +50만 원 |
| 대학생 개미 🎓 | 쉬움 | 시작 600만 원, 멘탈 회복 2배 |
| 큰손 개미 💰 | 어려움 | 시작 3,000만 원, 손실 때 멘탈 1.5배로 깎임 |
| 존버 개미 🗿 | 버티기 | 멘탈 하한 20(패닉셀 없음), 매매 수수료 2배 |
| 단타 개미 ⚡ | 매매 | 수수료 절반, 한 주 쉬기 보너스 없음 |
| 코인 개미 🪙 | 해금 | 코인 시장이 처음부터 열림, 시작 멘탈 50 |

- 라이벌 유튜버: 실제 채널마다 동물 아바타(여우·곰·토끼·판다·호랑이·고양이…)를 정해서 붙이고, 그 주 성적에 맞는 한마디를 한다("이번 주 +9%! 구독 좋아요 알림 설정!").
- 코치 부엉이 박사: 결산 때 AI 코치로 말하고, 개미 비서 답변도 부엉이 말풍선으로 보여준다.
- 사건 NPC: 팀장님(곰), 선배(너구리), 친구(햄스터), 엄마(토끼).

## 4. 시즌 미션(판마다 3개 무작위)

유튜버 2명 이상 이기기 · 코스피 이기기 · 멘탈 40 아래로 안 떨어지기 · 3종목 이상 나눠 담기(10주 이상) · 추격 매수 0번 · 코인 없이 +10% · 한 종목으로 +50% · 사건에서 저축 2번 · 패닉셀 없이 끝내기 …
미션 하나에 ★1, 등급 S·A는 ★2, B는 ★1 → 내 방 가구(책상·모니터·화분·트로피·황금 개미상·펜트하우스 창…)와 개미 옷(넥타이·선글라스·왕관…).

## 5. AI — 개미 비서(시점 제한 RAG)

- 문서: 언급 영상 제목(가려진 것)과 공시 제목, 주 단위. 종목 코드네임 토큰(⟦i⟧)이 그대로 저장돼 판마다 코드네임으로 바뀐다.
- 임베딩: Gemini 임베딩 → Supabase **pgvector**(로컬 개발은 같은 Postgres 컨테이너, DB가 없으면 메모리 검색).
- 검색 조건: `week ≤ 지금 보이는 주` AND `이번 판 종목`. 미래 문서는 SQL 단계에서 걸러져 모델에 아예 가지 않는다.
- 생성: Gemini, JSON 스키마(answer · cites[]), 검증(인용 id 실재 · 넘긴 숫자만 · 권유 금지 · 진짜 이름 노출 금지) → 1번 재시도 → 실패하면 검색 결과 요약으로 대체.
- 비용: 시즌당 3번, 서버 전체 분당 상한.

## 6. 3D(three.js · react-three-fiber)

- 직접 만든 로우폴리 캐릭터(구·캡슐 조합, 외부 모델 파일 없음).
- 홈: 내 방(★ 가구가 놓임)과 손 흔드는 내 개미.
- 플레이 피드: 화제 광장. 가판대(종목) 주위로 개미가 언급 수만큼 모이고, 가판대 높이는 지난주 등락.
- 결산: 등급 시상대.
- 저사양·`prefers-reduced-motion`·WebGL 미지원이면 2D로 대체하고, three.js는 화면에 보일 때만 받는다(코드 분할).

## 7. 일정
1. 서버: 연습 시즌·캐릭터 특성·미션·빨리 감기·RAG(임베딩·pgvector·질문 API)
2. 화면: 캐릭터 SVG, 리캡 카드, 빨리 감기, 미션·★·내 방, 개미 비서, UX 렌즈

5. 발표 자료(5주차 아이디어 공유) + 대본
