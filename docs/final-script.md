## 예상 질문과 답

**Q1. 실제 과거 데이터면, 그때 일을 기억하는 사람이 유리하지 않나요?**
종목은 판마다 새로 섞는 코드네임이고 시작 주도 40여 가지 중 무작위입니다. 영상 제목 속 날짜·'3월'·'추석' 같은 시점 단서와 제품·공장 이름도 지우고, 가격도 판마다 다른 배율로 보여 줍니다(등락률은 그대로). 정체는 결산 때만 공개합니다. 이야기 속 '기억이 흐릿해진다'가 바로 이 장치입니다.

**Q2. 데이터가 바뀌면 진행 중인 게임은 어떻게 되나요?**
갱신할 때 지난 팩의 종목과 순서를 그대로 지키고, 새 판은 종목 id 를 같이 저장해서 서버가 불러올 때 다시 연결합니다. 금요일 종가 전의 주는 넣지 않고, 지난 종가가 바뀌면 품질 관문에서 배포를 멈춥니다. 이 경우를 자동 테스트로 확인합니다.

**Q3. '실시간'은 왜 안 하나요?**
이 게임은 '과거를 다시 사는' 구조라 실시간 시세를 쓰면 정답이 사라집니다. 대신 원천은 매일 쌓이고, 시즌 팩은 주 단위로 갱신해 플레이할 수 있는 시장이 계속 늘어납니다.

**Q4. RAG가 미래 정보를 안 쓴다는 걸 어떻게 보장하나요?**
현재 주차는 화면이 아니라 서버의 판 상태에서 가져오고, 검색 SQL에 '주 ≤ 지금 주' 조건을 겁니다. 미래 문서는 모델에 들어가지도 않습니다. 자동 테스트가 매번 확인하고, 답은 인용 실재·권유·실명 검사를 통과해야 화면에 나갑니다.

**Q5. 사용성은 어떻게 검증했나요?**
모드별 완주율과 한 판에 걸린 시간을 서버가 직접 집계합니다. 26주였을 때 3~4주차에 그만두는 사람이 많아 12주로 줄였고, 12주 오늘의 시드는 78%가 끝까지 했습니다. 개선 55건은 무엇을 보고 무엇을 바꿨는지 docs/ux-log.md 에 남겼습니다.

**Q6. 보안은 어떤가요?**
로그인·개인정보가 없고 기기 표식은 무작위 문자열입니다. 콘텐츠 보안 정책·HTTPS 강제·다른 사이트 iframe 금지, IP+기기별 요청 한도(AI는 더 엄격), API 키는 서버 환경변수에만, 정답이 든 시즌 팩은 암호문으로만 저장소에 있습니다. 화면 라이브러리 취약점 0건입니다.

**Q7. 결국 운 아닌가요?**
한 주 단위 주가는 거의 무작위라 맞히기보다 버티기를 평가합니다. 멘탈 관리·분산·추격 매수 여부가 칭호와 미션으로 드러나고, 코스피 ETF로 '그냥 시장 사기'와도 비교됩니다. 실제로 많이 받은 칭호도 '균형 잡힌 개미'였습니다.

**Q8. 반도체·빅테크만 담으면 끝 아닌가요?**
데이터 기간이 AI 반도체 붐과 겹친 건 맞습니다. 하지만 같은 업종 안에서도 −70%부터 수천 %까지 갈렸고, 마지막 시작점들에선 반도체의 90%가 손실이었습니다. 업종은 힌트일 뿐이고, 수집 기간이 늘면 다른 국면이 들어옵니다.

**Q9. 그림과 소리는 어떻게 만들었나요?**
그림 32장은 Codex CLI의 이미지 생성(ChatGPT)을 스크립트(scripts/gen_image.sh)로 불러 같은 그림체·같은 주인공 문구를 고정해 만들었습니다. 소리는 파일 없이 Web Audio 로 합성한 효과음과 로파이 배경음악입니다.

**Q10. 수익 모델은요?**
현실적인 건 B2B 금융교육입니다. 증권사 신규 고객 온보딩이나 학교·기관 수업에서 반별 리그로 쓰고, 개인은 무료에 방 꾸미기 같은 코스메틱을 생각합니다.
