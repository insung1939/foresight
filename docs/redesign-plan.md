# Foresight 리디자인 계획 — 「타임슬립 개미」 (2026-11-21)

> **상태(2026-11-21)**: 방향 확정(타임슬립 개미 · 마감 1주 이내 → 0~2단계만 · 기존 10문제 게임 삭제). 1·2단계 구현 완료 — 시즌 팩, 서버 엔진, 26주 플레이, 사건 14종, 유튜버 고스트, 오늘의 시드 랭킹, 결산·공유·AI 코치, 칭호 도감·시장 해금, 첫 판 안내. 3단계(유튜버 모드·2.5D 방)는 하지 않음.

> 2025년 10월로 떨어졌다. 1,000만 원과 스마트폰 한 대. 진짜 시장에서 1년을 버텨라.

## 0. 왜 갈아엎나

지금 게임은 **10번의 퀴즈**다. 카드 3장을 열고, 비중을 고르고, 정답을 본다. 라운드끼리 연결되지 않아서 앞의 선택이 뒤에 영향을 주지 않고, 쌓이는 것도 없고, 다시 할 이유도 없다. 재미없는 이유는 UI보다 구조에 있다.

| 문제 | 원인 | 새 구조에서 |
|---|---|---|
| 판단이 하나씩 끊겨 있다 | 문제마다 다른 종목, 다른 시점 | **하나의 시간선**(주 단위)에서 포트폴리오가 계속 이어진다 |
| 긴장감이 없다 | 잃어도 다음 문제로 넘어가면 끝 | 자산과 멘탈이 다음 주로 넘어간다. 파산하면 게임이 끝난다 |
| 다시 할 이유가 없다 | 문제가 고정돼 있고 랭킹·성장이 약하다 | 판마다 코드네임과 시작 시점이 섞인다. 오늘의 시드 랭킹, 칭호, 해금 |
| hindsight 데이터가 장식에 그친다 | 유튜버 의견이 카드 한 장 | **유튜버 51명이 라이벌**이다. 실제 언급대로 샀을 때의 포트폴리오와 매주 순위를 겨룬다 |

## 1. 레퍼런스 분석 — 무엇을 가져오나

따라 만들지 않는다. 각 게임이 **왜 재미있는지**만 가져온다.

| 레퍼런스 | 재미의 원리 | 가져오는 것 |
|---|---|---|
| **킥루**(벤치에서 발롱까지) | 한 사람의 **커리어 한 번**을 은퇴까지 산다. 매 시즌 "진행" 버튼 하나로 빠르게 넘기고, 가끔 진로를 고른다. 숨은 성장 특성이 있고, 은퇴 기록이 일일 랭킹에 오른다. 계정 없이 자동 저장된다. | 1년 = 한 커리어. **[다음 주 ▶] 버튼 하나**로 굴러가는 템포. 매달 진로 선택 이벤트. 숨은 투자 성향. 결산 카드가 **오늘의 랭킹**에 자동 등록. 로그인 없이 자동 저장 |
| **전염병 주식회사** | 눈에 보이는 **확산 게이지**(지도·뉴스 티커). 내 선택이 확산 속도를 바꾸고, 반대 세력(치료제)과 경주한다. | 실제 유튜브 언급 수로 만든 **하이프 게이지**. 51개 채널로 소문이 퍼지는 걸 지도처럼 보여준다. 반대 세력은 **유튜버 라이벌과 코스피**. 확장 모드로 "내가 유튜버가 되어 종목을 퍼뜨리는" 모드(3단계) |
| **키자니아 주식 체험** | 진짜 직업을 **역할놀이**로 한다. 어린이도 바로 이해하는 용어와 실물 같은 소품을 쓴다. | 첫 판은 "증권사 첫 출근" 튜토리얼. 어려운 용어는 누르면 풀이가 나온다. 스마트폰 피드라는 익숙한 소품 |
| (보조) 듀오링고·워들 | 하루 한 판 습관, 이모지 결과 공유 | 오늘의 시드, `🟥🟥🟦🟥…` 주간 손익 공유 |

## 2. 게임 설계

### 핵심 판타지
"그때로 돌아가면 부자 될 수 있을 것 같지?" → **실제 시장을 실제 정보만 가지고** 다시 살아 보면 생각보다 어렵다는 걸 몸으로 느낀다. 기존 Foresight의 메시지(지나고 보면 쉬워 보인다)를 그대로 이어간다.

### 공정성: 기억으로 이기지 못하게
- 종목 이름은 **코드네임**으로 바꾼다. 예: `반도체 A`, `2차전지 C`, `밈코인 7`. 판마다 새로 섞는다. 업종·시장·시가총액 규모는 보여준다.
- 시작 주는 데이터 구간(2025-10 ~ 2026-11, 약 58주) 안에서 무작위로 정한다. 한 시즌은 **26주**(실제 반년, 플레이 약 10~12분).
- 유튜브 제목 속 종목명도 코드네임으로 바꾼다(기존 `masking.py` 재사용).
- 시즌이 끝나면 **"반도체 A는 사실 ○○였습니다"**를 공개한다. 기존 게임의 정답 공개 쾌감을 마지막에 몰아준다.

### 한 턴 = 실제 1주 (턴당 20~40초)

```
┌ 월요일 아침 ─────────────┐   ┌ 결정 ───────────────┐   ┌ 금요일 마감 ──────────┐
│ 📱 폰 피드                │ → │ 보유 최대 5종목        │ → │ 실제 주간 수익 카운트업 │
│ ▶ 유튜브: 실제 제목 3~5개  │   │ 매수/매도 = 바텀시트    │   │ 유튜버 라이벌 순위 변동 │
│ 📑 공시 · 🔥 하이프 게이지 │   │ 아무것도 안 하면        │   │ 멘탈 게이지 변화        │
│ 💬 단톡방 한 줄            │   │ [다음 주 ▶] 한 번       │   │ 가끔 사건 카드          │
└──────────────────────────┘   └───────────────────────┘   └────────────────────────┘
```

- **자산**: 현금 + 보유 종목 평가액. 수수료와 세금은 단순 비율로 반영해 잦은 매매에 비용이 든다.
- **멘탈(0~100)**: 큰 손실, 잦은 매매, 하이프 추격 매수 때 줄어든다. 쉬거나 분산하면 회복한다. 0이 되면 **"패닉셀" 강제 이벤트**가 일어난다. 전염병 주식회사의 게이지처럼 "숫자 말고 하나 더 신경 쓸 것"을 만들어 판단에 긴장을 준다.
- **하이프 게이지**: 그 주 51개 채널에서 나온 실제 언급 수와 증가율이다. 탭하면 채널 지도에 소문이 퍼지는 모습이 보인다.

### 매달(4턴마다) 인생 이벤트 — 킥루의 진로 선택
글로만 된 2지선다 카드 30장 정도. 만들기 싸고 다시 할 때마다 달라진다.
- "월급날. 50만 원 적립할까, 쓸까?"(적립하면 현금 +, 멘탈 −)
- "친구가 단톡방에 코인 링크를 보냈다"(밈코인 해금 + 리스크)
- "마이너스 통장 한도가 나왔다"(레버리지 해금 + 파산 위험)
- "부모님 생신"(현금 −, 멘탈 +)

### 라이벌 — hindsight만이 줄 수 있는 것
- 같은 26주 동안 **실제 유튜버 3명(무작위)이 영상에서 "오른다"고 한 종목을 그대로 샀다면** 어땠을지 계산한 고스트 포트폴리오. `stats.event_returns`와 `mentions`에서 만든다.
- 그리고 **코스피 그냥 들고 있기** 고스트.
- 매주 마감 때 순위표가 바뀐다. 목표 문구는 "유튜버를 이겨라, 그리고 코스피를 이겨라".

### 결산 — 커리어 카드
- 최종 수익률, 등급(S~F), 칭호(예: "존버의 신", "FOMO 장인", "손절 머신"). 칭호는 숨은 성향 4축(분산, 추격 매수, 보유 기간, 손절)으로 정한다.
- 유튜버와 코스피를 합친 순위, 코드네임 정체 공개, 내 최고와 최악의 거래 다시 보기.
- 이미지 저장 및 공유(이모지 주간 그리드). 오늘의 시드 랭킹에 자동 등록된다.
- (선택) AI 코치 한 줄 평. 기존 Gemini 연동을 재사용한다.

### 성장과 다시 하기
- **오늘의 시드**: 모두 같은 시장, 같은 코드네임으로 한 판. 일일 랭킹.
- **자유 플레이**: 시드가 무작위다.
- **해금**: 첫 판은 국내 주식만. 결산 B 등급 이상이면 미국 주식 → 코인 → 레버리지 순으로 열린다. 레벨이 아니라 **선택지가 늘어나는 성장**이다.
- 칭호와 배지 도감(수집). 기존 배지 시스템을 재활용한다.

## 3. UI/UX — 모바일 우선, 용어집 기준

교수님 강조점: 적절한 UI/UX, 쓰기 편함, 모바일 반응형. 11주차 **UI/UX 용어집**의 용어를 설계 근거로 쓰고, 발표에서도 그 용어로 설명한다.

| 원칙 / 용어집 용어 | 적용 |
|---|---|
| **Bottom Sheet** | 매수·매도·종목 상세는 모두 바텀시트로 띄운다. 피드 맥락을 잃지 않는다 |
| 엄지 영역 · **Active/Pressed State** · **Haptic Feedback** | 주 행동 [다음 주 ▶]는 화면 하단 고정, 높이 56px. 누르면 진동(`navigator.vibrate`) |
| **Progressive Disclosure** | 첫 판은 유튜브와 차트만 보인다. 공시·하이프·레버리지는 해금될 때 **"New" Badge**를 단다 |
| **Onboarding Flow** · **Coach Marks** | "증권사 첫 출근" 3단계. 코치마크는 최대 3개, 언제든 건너뛸 수 있다 |
| **Undo / Redo** · **Confirmation Pattern** | 주 마감 전 거래는 취소할 수 있다. 전량 매도와 레버리지만 확인을 받는다 |
| **Toast Feedback** · **Optimistic UI** | 체결은 즉시 반영하고 토스트로 알린다 |
| **Skeleton Screen** · **Loading/Empty/Error State** | 시즌 데이터를 받는 동안 스켈레톤. "이번 주 공시 없음" 같은 빈 상태 문구. 서버가 깨어날 때 안내 |
| **Autosave** | 매 턴 자동 저장. 새로고침해도 이어서 한다 |
| **Tooltip vs Popover** | 용어(PER, 공매도 등)는 탭하면 팝오버로 풀이한다. 키자니아식 쉬운 말 |
| 접근성(색만으로 말하지 않기, Reduced Motion) | 상승 빨강▲ 하락 파랑▼. `prefers-reduced-motion`이면 카운트업과 지도 애니메이션을 끈다 |
| 반응형 | 360~430px 기준으로 설계한다. 태블릿·데스크톱은 피드와 포트폴리오를 2단으로 배치한다. 프로젝터 시연용 큰 글자 모드 |

**한 화면에 한 가지 결정**은 기존 원칙대로 유지한다. 피드 → 결정 → 마감이 한 턴이다.

## 4. 3D(GTA 같은 요소)에 대한 판단

GTA식 오픈월드 3D는 **추천하지 않는다.**
- 일정 안에 끝낼 수 없고, 모바일에서 무겁고(배터리·발열·로딩), 평가 항목인 "쓰기 편함"과 충돌한다.
- 이 게임의 재미는 판단과 결과에서 나온다. 이동과 탐험에서 나오지 않는다.

대신 **3단계 선택 과제**로 가벼운 2.5D "내 방"을 제안한다(react-three-fiber, 로우폴리). 자산이 늘면 원룸 → 오피스텔 → 펜트하우스로 바뀌고, 결산 화면 배경으로 쓴다. 3D가 주는 "눈에 보이는 성공"만 가져오는 방식이다. 저사양 기기와 reduced-motion 환경에서는 2D 일러스트로 대체한다.

## 5. 수익화 가설

| 모델 | 내용 | 근거 |
|---|---|---|
| 무료 + 코스메틱 | 방 꾸미기, 칭호 테두리, 시즌 패스 | 플레이에 영향 없는 과금. 투자 게임의 공정성 유지 |
| 보상형 광고 | 파산 직전 "멘탈 회복 1회", AI 코치 상세 리포트 | 게임 흐름을 끊지 않는 자리에만 |
| **B2B 교육** | 증권사 신규 고객 온보딩, 학교·기관 금융교육(키자니아 모델). 반·기수별 리그 | 실제 데이터 기반이라는 차별점. 가장 현실적인 매출원 |
| 스폰서 대회 | 월간 시즌 리그 | 일일·월간 랭킹 인프라 재사용 |

규제: 과거 데이터 기반 시뮬레이션이고 투자 권유가 아니다. 결산 전까지 실제 종목명을 노출하지 않는다. 실시간 종목 추천 기능은 없다(기존 원칙 유지).
