## 비용
- Gemini 무료 등급: 생성은 분당 한도가 있어 평가는 5초 간격으로 돌렸다. 임베딩은 모델마다 하루 약 1,000문장이라 색인을 하루씩 늘린다.
- 판당 AI 호출: 개미 비서 최대 3번(+VIP 카드 3번) + 코치 1번. 호출마다 토큰 수를 `ai_calls` 표에 남긴다.
- 서버: Render 무료(처음 깨울 때 약 30초 — 발표 전 미리 열어 두기), DB: Supabase 무료, 화면: Vercel 무료.

## 보안·개인정보
- API 키는 서버 환경 변수에만(화면 코드·저장소에 없음). 정답이 든 시즌 팩은 암호문(`data/pack.enc`)만 공개 저장소에.
- 로그인 없음, 개인정보 저장 없음(기기 표식은 무작위 문자열). 닉네임은 욕설 거르기·12자.
- 요청 한도(IP+기기, AI 질문은 더 엄격), 같은 판 동시 요청 잠금, 보안 헤더, 게임 응답 캐시 금지, CORS 허용 주소만.
- 미래 정보 차단: 다음 주 가격·진짜 이름·날짜는 서버가 턴을 처리하거나 판이 끝나야 보낸다. 테스트가 매 턴 확인한다.

## 운영 `/v1/meta` 의 지연 값 읽는 법
- `ask.p50` 은 **최근 50번** 호출의 중간값이다(예전엔 전체 누적이라 최적화 전 호출이 섞여 15초대로 보였다).
