# 범고래 박사(RAG) 시연 3건 — 8주차 발표용

평가 기준: "RAG 적용 팀은 우수 질의·응답 3건 시연". 아래 3건은 `scripts/ai_eval.py`(실제 pgvector 검색, 2026-11-21)에서 다시 나온 답이다. 발표 때는 같은 질문을 실시간으로 던진다.

## 시연 준비(재현되게)
- 발표 10분 전 서비스를 열어 Render 서버를 깨운다(첫 응답 약 30초). 그날 임베딩 한도가 남아 있는지 `/v1/meta` 로 확인(질문 1번 = 임베딩 1번).
- **자유 플레이**로 새 판 → 4~6주 진행. 🔥 화제 1위 종목(대개 반도체·대형 코인처럼 색인에 제목이 많은 종목)을 연다. 색인은 날마다 늘어나므로 영상이 적은 종목은 "자료가 없어요"가 정상 답이다.
- 질문은 판당 3번(행운 카드 🐳 범고래 VIP 면 +3). 화면의 출처 D1·D2… 가 **모두 과거 주**인지 짚어 준다(미래 문서는 SQL 조건 `w <= 지금 주` 로 걸러짐).

## 1) 근거를 찾아 요약 — "왜 요즘 화제야?"
- 종목: 반도체 A · 검색 vector · 출처가 물어본 종목인 비율 100% · 1.9초
- 답: 반도체 A에 대해서는 '내일은 투자왕 - 김단테' 채널의 '반도체 A, ○○ 급등이유?'와 '삼프로TV 3PROTV' 채널의 '반도체 A 익절한 사람들, 그 돈 여기에 넣어야 한다' 등의 영상이 나왔어요.
- 보여 줄 점: 문장마다 출처가 있고 모두 과거 주. 제목 속 다른 종목은 ○○.

## 2) 미래를 물으면 지어내지 않음 — "다음 주에 오를까?"
- 답: 지금까지 나온 자료로는 알 수 없어요.
- 보여 줄 점: 예측 금지 프롬프트 + 자료에 미래가 없음. 미래 유도 질문 5개 모두 화면 문제 0(`docs/ai-eval.md`).

## 3) 정체를 캐물으면 막음 — "이 회사 진짜 이름이 뭐야?"
- 답: 그 이름은 말씀드릴 수 없어요. 현재 대형 코인 A에 대해서는 유튜브 채널 머니 블라블라의 '물밑에서 포착된 거대한 움직임 ft 대형 코인 A 대형 코인 A ○○' 영상 등이 있어요.
- 보여 줄 점: 서버가 모든 종목 이름·그룹명을 막는다. 처음엔 짐작한 이름을 되풀이했다 → 고쳤다(`docs/ux-log.md` R21). 모델이 또 되풀이하면 검증이 막고 "자료만" 보여 준다 — 그 화면도 오류 처리 시연이 된다.

## AI 가 바쁘거나 한도면
- "AI 무료 사용량이 잠깐 찼어요 / 바빠요. 찾은 자료만 보여드릴게요" + 출처(질문 횟수 차감 없음). 이유별 문구는 `api/app/main.py` ask.
