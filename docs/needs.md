# Needs·문제 정의·시장

## 대상과 문제
- 대상: 유튜브·커뮤니티로 종목 정보를 얻는 개인 투자자, 투자 입문자.
- 문제 1: 유튜버 말이 얼마나 맞았는지 확인할 방법이 없다.
- 문제 2: 실전 연습은 진짜 돈을 잃고, 결과를 알기까지 몇 주가 걸린다.
- 문제 3: 정보가 넘치는데 무엇을 보고 판단할지 연습할 곳이 없다.
